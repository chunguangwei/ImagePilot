# 照片创玩 - 本地滤镜 + 本地 AI 超分

## 一、照片处理的痛点

### 传统照片编辑的困扰

**操作复杂，学习成本高**
- 需要学习Photoshop、Lightroom等专业软件
- 需要了解各种工具和参数（曲线、色阶、修复画笔等）
- 需要手动调整每个细节，反复尝试才能找到最佳效果
- 对普通用户来说，门槛太高，难以掌握

**隐私与联网顾虑**
- 很多在线修图工具需要把照片上传到服务器处理
- 依赖网络，照片离开本机存在隐私顾虑

**效果难以把控**
- 不知道如何调整参数才能达到想要的效果
- 容易过度修饰，失去照片的自然感
- 处理结果往往不如预期
