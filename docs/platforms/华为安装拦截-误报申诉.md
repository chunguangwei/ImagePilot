# 华为"恶意安装来源"拦截 — 根因与误报申诉

## 现象
华为（纯净模式/HarmonyOS）上点 ImagePilot 应用内更新时，系统弹：
> 发现恶意安装来源，该安装来源可能被恶意篡改，禁止安装。

同机的译人/Airsonic（同为侧载、同款安装实现）不受影响。

## 根因分析（2026-06-11）
- 拦的是**发起安装的应用**（ImagePilot 作为"安装来源"），不是被装的 APK。
- 排查结论：安装实现（REQUEST_INSTALL_PACKAGES + canRequestPackageInstalls + FileProvider content://）、
  签名方案（v2+，CI 正规 keystore）、targetSdk(35) 与译人完全同款 → 代码差异排除。
- 最可能根因：**包名 `com.imageclassifier.v2` 历史上同时流通过 debug 签名与 release 签名版本**
  （早期真机调试装过 debug 包，vivo 也出过"签名不匹配"），华为云端信誉库据此判定
  "同包名签名不一致 → 可能被篡改"。译人始终单一签名，故无此问题。

## 已做的 App 内缓解（v1.5.38 起）
1. 更新 APK 下载位置改为公共 `Download/` 目录（系统文件管理可见）。
2. 华为/荣耀设备拉起安装后弹引导：
   - 方法一：设置 → 系统和更新 → 纯净模式 → 关闭后重试
   - 方法二：文件管理 → Download → 点按 imagepilot-update.apk 安装（换"安装来源"绕开信誉判定）

## 根治：华为开发者联盟误报申诉
入口：华为开发者联盟（developer.huawei.com）→ 智能终端服务 → 安全检测 / 应用安全检测申诉
（不要求应用上架；个人开发者账号可提交）。

提交材料（拟好可直接用）：
- 应用名：ImagePilot（包名 com.imageclassifier.v2）
- 申诉类型：恶意应用/安装来源 误报
- 说明：
  > 本应用为开源的本地相册整理工具（仓库 https://github.com/chunguangwei/ImagePilot ，
  > PolyForm Noncommercial 许可）。应用完全本地运行，不上传用户照片；应用内更新仅从
  > 本仓库 GitHub Releases 下载官方签名 APK 并调用系统安装器（REQUEST_INSTALL_PACKAGES +
  > FileProvider，标准流程）。近期被纯净模式判定为"恶意安装来源/可能被恶意篡改"，
  > 疑因开发调试期同包名存在过 debug 签名包导致签名档案不一致。现提交官方 release 签名
  > APK 与签名证书指纹，请复核并解除误报。
- 附件：最新 release APK + 签名指纹（`apksigner verify --print-certs ImagePilot-android-arm-<版本>.apk`）

## 预防
- 测试机不要再安装 debug 签名的同包名版本（用模拟器或先卸载）。
- 签名 keystore 永不更换（CI Secrets 持续使用同一份）。
