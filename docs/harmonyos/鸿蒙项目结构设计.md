# 鸿蒙项目结构设计

## 📋 设计原则

**核心原则**：保持代码结构一致，仅增加鸿蒙原生目录

- ✅ JavaScript代码（`src/`）完全共享，无需修改
- ✅ 仅增加 `harmonyos/` 目录存放鸿蒙原生代码
- ✅ 依赖和构建配置都在 `harmonyos/` 子目录中
- ✅ 通过平台检测（Platform.OS）区分平台

#### src/adapters/WebAdapters.js

需要添加鸿蒙平台检测和适配：

```javascript
import { Platform } from 'react-native';

// 扩展平台检测
export const Platform = {
  OS: Platform.OS, // 'android' | 'ios' | 'web' | 'harmonyos'
  isHarmonyOS: Platform.OS === 'harmonyos',
  isAndroid: Platform.OS === 'android',
  isIOS: Platform.OS === 'ios',
  isWeb: Platform.OS === 'web',
};

// 文件系统适配
export const RNFS = {
  readFile: async (filePath, encoding) => {
    if (Platform.OS === 'harmonyos') {
      // 使用鸿蒙文件系统API
      const { HarmonyOSFS } = require('react-native-oh-library/react-native-fs');
      return await HarmonyOSFS.readFile(filePath, encoding);
    } else if (Platform.OS === 'android') {
      // 使用Android文件系统API
      const RNFS = require('react-native-fs');
      return await RNFS.readFile(filePath, encoding);
    }
    // ... 其他平台
  },
  // ... 其他方法
};

// 图片选择器适配
export const launchImageLibrary = (options, callback) => {
  if (Platform.OS === 'harmonyos') {
    // 使用鸿蒙图片选择器
    const { HarmonyOSImagePicker } = require('react-native-oh-library/react-native-image-picker');
    return HarmonyOSImagePicker.launchImageLibrary(options, callback);
  } else if (Platform.OS === 'android') {
    // 使用Android图片选择器
    const ImagePicker = require('react-native-image-picker');
    return ImagePicker.launchImageLibrary(options, callback);
  }
  // ... 其他平台
};
```

#### src/services/MediaStoreService.js

需要添加鸿蒙平台支持：

```javascript
import { NativeModules, Platform } from 'react-native';

const { MediaStoreModule } = NativeModules;
// 鸿蒙平台使用不同的模块名
const { MediaLibraryModule } = Platform.OS === 'harmonyos' 
  ? require('react-native-oh-library/harmonyos-media-library') 
  : { MediaLibraryModule: null };

class MediaStoreService {
  constructor() {
    if (Platform.OS === 'android') {
      this.isAvailable = MediaStoreModule != null;
      this.module = MediaStoreModule;
    } else if (Platform.OS === 'harmonyos') {
      this.isAvailable = MediaLibraryModule != null;
      this.module = MediaLibraryModule;
    } else {
      this.isAvailable = false;
      this.module = null;
    }
  }
  
  // 统一接口，内部根据平台调用不同实现
  async getAllImages(options = {}) {
    if (Platform.OS === 'android') {
      return await this.module.getAllImages(options);
    } else if (Platform.OS === 'harmonyos') {
      return await this.module.queryImages(options);
    }
    throw new Error('Unsupported platform');
  }
}
```

## 五、平台检测和适配

### 5.1 平台检测

在代码中使用 `Platform.OS` 检测平台：

```javascript
import { Platform } from 'react-native';

if (Platform.OS === 'harmonyos') {
  // 鸿蒙平台特定代码
} else if (Platform.OS === 'android') {
  // Android平台特定代码
} else if (Platform.OS === 'ios') {
  // iOS平台特定代码
} else if (Platform.OS === 'web') {
  // Web平台特定代码
}
```

### 5.2 适配层设计

在 `src/adapters/WebAdapters.js` 中统一处理平台差异：

```javascript
// 统一的文件系统接口
export const RNFS = {
  readFile: async (filePath, encoding) => {
    switch (Platform.OS) {
      case 'harmonyos':
        return await harmonyosFS.readFile(filePath, encoding);
      case 'android':
        return await androidFS.readFile(filePath, encoding);
      case 'ios':
        return await iosFS.readFile(filePath, encoding);
      default:
        throw new Error(`Unsupported platform: ${Platform.OS}`);
    }
  },
  // ... 其他方法
};
```

## 六、开发工作流

### 6.1 开发流程

1. **修改共享代码**（`src/`）
   - 修改业务逻辑、UI组件等
   - 所有平台共享

2. **修改平台特定代码**
   - Android: `android/` 目录
   - 鸿蒙: `harmonyos/` 目录

3. **运行和测试**
   ```bash
   # Android
   npm run android
   
   # 鸿蒙
   npm run harmonyos:dev
   ```

### 6.2 构建流程

```bash
# 1. 安装依赖
npm install

# 2. 启动Metro服务器（共享）
npm start

# 3. 构建Android版本
npm run android

# 4. 构建鸿蒙版本
npm run harmonyos:release
```

## 八、注意事项

### 8.1 平台差异处理

- 使用适配层（`WebAdapters.js`）统一处理平台差异
- 避免在业务代码中直接使用平台特定API
- 通过 `Platform.OS` 检测平台，使用适配后的接口

### 8.2 原生模块

- Android原生模块在 `android/app/src/main/java/`
- 鸿蒙原生模块在 `harmonyos/entry/src/main/ets/react-native/modules/`
- 通过适配层统一暴露给JavaScript

### 8.3 资源文件

- 共享资源放在 `public/` 目录
- 平台特定资源放在各自平台目录
- 通过适配层统一访问路径
