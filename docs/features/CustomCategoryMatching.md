# 自定义分类匹配（1.5.95）

保留 id、名称、规则、图标与旧数据；不自动拆分原规则。新增可选 scenarios（场景数组）和 exclusions（排除对象文字），存入原 settings.aiProvider.customCategories，备份沿用完整对象。

手机表单默认保持简单，展开“匹配细节”后可填写每行一个场景。不同场景分别编码，文本都带原规则，不用宽泛名称替代规则。最大场景分数作为类别证据，与所有启用的内置、自定义类别竞争；没有自定义优先加分。无场景时沿用完整单条规则。

排除对象单独编码，不进入正向类别原型；如果最终胜出类别的正向分数未显著超过排除分数，判为不确定，不把排除对象提升为分类结果。1.5.96起不确定归入“其他”。该机制只是相似度冲突检查，不能保证执行否定、计数、OCR 或逻辑条件。E2B/在线模型收到原规则、可选场景和排除说明，由用户主动选择引擎。

缓存键包含全部场景与排除文本，编辑后重新编码。旧分类不会自动重算；1.5.96起主动分类的拒判结果归入“其他”，保留已有描述；普通扫描不重分类已归档照片。诊断导出包含实际场景及排除文字，请检查后分享。

验证涵盖旧规则不拆分、场景保留规则、排除不污染正向证据、同分回退检查最终候选、空规则时 E2B 仍接收细节、缓存失效、编辑折叠状态保存与失败重试。模型实际效果需用户图库验证；多场景意味着额外文本编码，不能宣称零开销。
