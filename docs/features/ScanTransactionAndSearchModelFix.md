# 扫描事务与搜索模型入口修复（1.5.93）

1.5.92 用户反馈刷新提示 `there is no current transaction`。定位到原生扫描的删除记录步骤：beginTransaction 失败后，无条件 finally/endTransaction 掩盖原始错误。使用生产方法与故障数据库桩复现，修复为仅在事务启动成功后结束一次，锁冲突最多重试三次，提交成功后才返回成功。扫描检查删除结果，失败不得继续报告清理成功。错误界面增加可理解的重试提示，原错误保留日志。

设置分类区使用折叠向右、展开向下的箭头。分类仍只有 EmbeddingGemma 和 E2B。

MobileCLIP2 S2（约147 MB）保留为独立的向量搜索依赖，1.5.92 没有删除已下载文件或索引，但隐藏分类卡片误使缺少模型的用户无法下载。现将下载、进度和取消放入“相似照片与搜索 → AI 向量索引”，下载后不更改分类选择。旧深链接同样只下载搜索依赖，移除首页旧CLIP分类升级弹窗。已有索引保留，可继续补全。颜色相似不依赖此模型；其他图像增强模型入口不变。

验证：生产删除方法故障测试覆盖正常提交、临时锁、持续锁、删除失败、提交失败；修复前复现异常，修复后五种情况通过。Android 原生编译、生产 JS bundle 及199项应用测试通过。实际手机仍需验证扫描刷新与下载后补全索引。本修复纳入 1.5.93。
