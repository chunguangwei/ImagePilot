# 不确定分类策略（1.5.96）

Gemma 2 是 EmbeddingGemma 2 的产品显示名，内部embeddinggemma2标识、文件名和校验值不变。

- 完成推理但证据冲突、领先不足、无有效正向匹配：category=other，accepted=false，fallbackCategory=other；原描述保留，相似度不当作概率。
- 推理抛错、文件不可用：不写分类，计失败，允许重试。用户停止时保留已经完成的结果，未处理项不写新结果。
- 普通扫描仅查询NA/NA_video，不重新处理已分类/手动分类照片。用户主动选单张、批量或目录重分类时允许按新结果调整，包括不确定归Other。
- Android/iOS扫描均复用embeddingRecordFields保存诊断；批量保存成功后更新共享缓存、目录计数并通知订阅者。保存失败不假报成功。
- 图片详情的新记录显示“已归入其他”，历史未包含fallbackCategory的诊断仍按旧语义显示，避免谎称旧照片已移动。手动改类后保留的诊断代表历史AI运行，不代表当前手动分类。
- 搜索图像的临时分类不写图库；不确定时不采用候选类别过滤搜索。LFM/SmolVLM已下线，不重新启用。

测试覆盖双端NA/已有类别/视频不确定归Other，异常不写入、普通扫描范围、共享缓存Other计数与旧目录减计数、描述保留、模型显示改名后文件身份兼容。
