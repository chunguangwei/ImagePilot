# 分类模型选择与连续选图

入口：首页长按分类目录（包括其他及已分类目录）、分类页选图后AI分类、照片预览页“分类 → 选择模型重新AI分类”。每次选择只用于本次任务，不修改默认模型或默认在线Provider。

已分类目录、其他目录及照片预览的重分类列表：本地小模型全部列出：Gemma 2、物体识别（MobileNetV3）、场景识别（Places365）、MobileCLIP。本地大模型列出Gemma4-E2B。依据实际文件状态显示“使用此模型”或“下载+大小”，下载复用原国内外备用源，可取消，完成后主动点使用。本次选择仅一模型，不叠加推理；LFM/SmolVLM继续下线。

传统小模型只支持预设类别，不支持自定义规则、不生成描述；Gemma 2支持自定义类别但不生成描述；E2B支持分类和描述。列表明确能力差异。

在线只显示手机端支持、配置了模型及地址且存在凭据的Provider，每个Provider展示当前配置的模型；未配置的不显示。桌面专用Ollama不在手机列表。选择在线时提示图片发送至所选服务，不自动从本地切到在线。任务使用选定Provider配置快照，不写全局设置。

文件缺失、推理失败保持失败状态，不因用户选择了传统模型而静默换用另一个模型或把错误当作Other。分类完成的有效不确定结果沿用Other策略。推理前再次检查文件；取消下载后重新打开可继续操作；同时只运行一个由选择器启动的任务。

照片预览更新按开始时的图片ID回写本地视图：用户切到另一张图时，不把旧任务结果显示到新图上。图库仍经统一保存接口刷新目录计数。

验证：选择列表/下载取消后重开、默认配置不变、双端任务tier与Provider传递、显式引擎失败不兜底；269项自动测试/34套通过；Android与iOS生产JS bundle均成功，独立审查的阻塞问题已修复。双端发布与安装验证见对应发布记录；尚未完成新增功能的真机UI交互实测。

## 待分类入口与选择状态（1.5.98）

“待分类图片”和“待分类视频”（包括首页统一待分类按钮）使用精简底部面板：只列设置中的默认本地模型及已配置的在线服务，默认选本地，点“开始分类”执行。模型未下载时按钮改为下载，完成后再确认开始。在线服务说明照片将上传，不修改默认模型。已分类目录仍保留全部本地模型选择。

分类目录内“取消”“完成”及离开页面均清除本次选中标记。重新进入恢复浏览模式，缓存刷新也不再从旧标记自动恢复多选。

长按照片后不松手滑动，按屏幕顺序选中连续区间，可跨日期；滑回会收回本次扩展的区间，保留手势开始前的其他选择。从已选照片长按滑动可连续取消。停在上下边缘会滚动，松手停止。普通滑动仍滚动列表；也支持逐张点选与全选。

## 视频“其他”补判（1.5.98）

Android、iOS 的本地与在线分类均先识别视频中点帧。只有有效结果为“其他”时，才在 15–30%、65–80%、85–95% 时间段各随机抽一帧，最多补判三次、串行处理。至少两张不同画面的有效结果一致才采用；冲突、无共识或抽帧失败保留“其他”。文件哈希去重避免同一帧重复计票。选定模型、用户分类规则保持一致，任务停止后不继续抽帧，临时文件及时清理。在线补判会产生额外图片请求；已有明确分类的视频不增加请求。

1.5.98 验证：284 项自动测试/39 套通过；Android Java 与 iOS Release 原生编译通过。真机交互与视频模型效果仍需实际测试，自动测试不代表设备端识别准确率。
