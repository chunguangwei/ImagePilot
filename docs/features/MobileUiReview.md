# 移动端 UI 与交互审查

日期：2026-11-06。状态：随 1.5.91 提供；不改变 1.5.90 的分类引擎或模型文件。

## 产品方向

ImagePilot 以设备端照片整理为主。优先让用户选模型、启动整理、理解结果；API 配置保留为用户主动选择的替代方案。使用现有蓝白/深色主题，不新增下载或网络依赖。

## 审查和处理

| 问题 | 改动 |
| --- | --- |
| 模型说明、下载、选择、删除挤在长列表里 | 三个主要模型独立卡片；一句用途、大小、文字状态；详情与管理折叠 |
| E2B 重复标题、名称截断 | 合并为完整 Gemma4-E2B 名称，自然换行 |
| 已下载和使用中的对勾含义混淆 | 分别显示使用中、已下载、未下载、下载中、校验中、本机暂不可用 |
| 下载时提前高亮、取消后旧任务覆盖新状态 | 保存成功再更新选中；取消等待任务退出；下载期间禁用其他选择和管理 |
| 当前传统模型容易藏起来 | 默认收起传统分组，但当前使用传统模型时展开 |
| 分类入口依赖长按 | 首页显示开始分类及待处理数量，含照片和视频；长按入口保留 |
| 所有忙碌任务都显示停止，但有些无法停止 | 服务进入可停止阶段才开放停止；请求后禁用重复点击，显示停止状态 |
| 任务进度藏在信息图标后 | 运行时直接显示状态文字，完成信息仍可从页头查看 |
| 图片描述和类别位于大量 EXIF 之后 | 类别和描述置顶；语义匹配候选及分数收起，异常/待处理提示保留 |
| 分类保存失败仍清空表单、反馈成功 | 存储成功后更新列表；失败保留草稿；保存中禁止重复提交和关闭编辑遮罩 |
| 隐藏内置分类被说成删除 | 改称隐藏，说明照片未删除、恢复可回到原类别 |
| 小字和触控区不足 | 新模型卡片操作区至少 48 点；重要说明提高对比度；无障碍角色、选中/展开/进度状态 |
