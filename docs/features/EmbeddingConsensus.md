# EmbeddingGemma 一致性检查与分类诊断（1.5.94）

用户确认1.5.93每次重新分类仍将网络机柜归为植物。此前iOS附件对照不能证明Android真机已解决；Android模拟器在模型初始化SIGILL，没有分类分数。无法连接真机，现先增强决策与远程诊断，不宣称已定位模型误判根因。

## 策略

保留现有类别向量均值排序，同时复用每条描述已编码的向量，计算最匹配的两条描述的平均相似度。两路最高类别必须一致，且各自领先幅度均达到现有0.005才自动接受。自定义规则仅一条时按该规则匹配，不附加通用内置例子。不按文件名、特定机柜图片或目标类别硬编码，不修改权重、不生成描述、不调用云端。

版本标识prototype-consensus-v2。证据冲突返回prototype-disagreement，描述支持间隔不足返回weak-prototype-support；保留已有分类或待分类，详情明确本次未自动改类。这降低冲突时强行分类的风险，但不保证本身一致的错误预测能被纠正，也可能增加需人工确认的照片。

## 性能与诊断

类别均值和逐描述向量一起缓存，新增点积计算，不增加图片或文本模型调用。每次分类保存平台、应用版本、算法版本、输入最长边配置、实际类别提示词、全部类别分数和逐描述分数。沿用已有JSON字段，不改变图片描述。

图片信息→匹配详情→导出分类诊断，用户主动通过系统分享面板选择去向。导出含自定义类别和规则原文，界面明确说明；不附带照片、图片文件路径或EXIF位置。只有新跑结果带诊断，所有旧算法结果显示重新分类提示。

## 验证

219项应用测试通过，Android生产JS bundle通过。新增覆盖证据冲突、间隔不足、维度检查、自定义单规则、诊断落库及不增加推理调用。已有七张真实iOS原生记录中两路类别一致且间隔过线，七张均保留原正确类别；这是对已记录分数的策略回放，不是新增Android真机测试，也不是总体准确率提升证明。

本变更纳入1.5.94，已正式发布，构建和下载验证见[1.5.94发布记录](../releases/v1.5.94.md)。Android机柜原图需后续实机重新分类并导出诊断验证。
