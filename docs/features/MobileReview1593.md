# 1.5.93 代码与移动 UI 审查

范围：移动首页、分类目录、图片预览、设置/模型管理、自定义分类、搜索、相似照片、收藏、统计、备份恢复，以及时刻、展映选择/创建/播放、滤镜、文档矫正、物体消除、增强结果的源码操作与异步状态检查。不是所有设备尺寸和主题的逐屏真机验收。

## 本次落实

- 扫描：原生事务开始失败不得结束未开始的事务；锁冲突有限重试；提交失败不报告成功。JS 原生启动拒绝不会遗留未观察的 rejected Promise。
- 搜索：切换查询清除旧批量选择，文本查询立即使旧请求失效，清空输入及时结束加载；AI 搜图开始/关闭同样隔离旧结果。E2B 不再依赖旧基础分类器初始化。错误和无结果分开，支持重试。
- 下载：RNFS iOS 取消可能只回传 resume data 而不结束 Promise，统一竞速取消信号并清除监听；保留大文件续传策略。取消时不自动换源，取消按钮有收尾反馈。
- 模型设置：仅两个分类器；独立 MobileCLIP 下载服务向量搜索，不切换分类器。折叠箭头统一关闭向右、展开向下。
- 界面：搜索、统计、相似组、收藏、备份返回按钮补充44点触控和可访问性标签；文档矫正/消除保存使用同步锁防止重复写入，保存期间禁止重做。取消相似组操作不弹失败。
- 文案：图片信息不再推荐已下线 SmolVLM；历史分类记录缺少算法版本时说明需重新分类。保留旧图片描述，不伪造生成描述。

## 验证边界

应用回归测试、Android 原生事务故障测试与编译、生产 JS 打包和 iOS 构建作为发布门槛。机柜原图当前 iOS 原生分类为电子产品，旧单中文文本路径为植物；不能据此推定 Android 反馈的唯一根因或声称准确率已全面提高。继续保留现有低间隔拒判策略，不为单张图硬编码类别或调整阈值。

Android 删除确认/拒绝、扫描锁冲突后的重试、更新下载安装、iOS 取消下载及长图库压力仍需真机验证。国内外下载沿用现有校验和失败切换，第三方代理不是自有大陆 CDN。

发布前验证：208 项应用测试通过；Android Java 编译通过；生产事务方法五类故障回归通过；生产 Android JS bundle 通过；独立代码复核已解决两项 P2。设备与发布结果见版本发布记录。
