# SmolVLM-500M 独立替换实验（1.5.92）

> **1.5.92 最终方案：** 线上只提供 EmbeddingGemma 2（快速分类、不生成描述）和 Gemma4-E2B（多模态分类与描述）。LFM/SmolVLM 已下线，旧选择迁移至 EmbeddingGemma，缺少文件需主动下载；已有分类与描述保留。下文旧模型试验属于历史记录，不是当前可用功能。


用户指定替换 LFM 后发布供手机对比。独立方案保留，不默认组合其它模型或调用外部 API。设置明确标为实验方案。

## 文件与迁移

采用 ggml-org/SmolVLM-500M-Instruct-GGUF 的 Q8_0 主模型（436806912字节）与 Q8_0 视觉文件（108783360字节），总545590272字节。HF 版本固定为72e986006ef53e37cdd3f6d4241c90b0f01df376；ModelScope同仓库双路，两个文件独立校验SHA-256。

旧设置键 classifierModelTier=lfm 保留兼容，新的文件名和状态校验防止旧LFM被误认为SmolVLM。需要主动下载新权重，管理中可主动删除旧LFM文件；不自动下载或删除。新结果仍使用兼容lfm元数据容器，但 model 为 smolvlm-500m-instruct；旧记录继续显示LFM，不伪装成新模型结果。

## 行为

全部有效内置和自定义类别进入提示，规则不丢弃。一次模型调用输出受约束JSON，类别严格映射回ID；英文描述，中文界面分类名仍本地显示。中文自定义规则理解有限，不调用云端翻译。保留既有描述，新辅助描述写入模型元数据。批处理中断恢复沿用既有独立模型流程。

## 实测结论与限制

隔离iOS模拟器，原生llama.rn、同一组六张回归图，实际生产分类函数并写入SQLite：机柜→单人照片（错）、奖杯→单人照片（错）、人像→单人照片（对）、猫→单人照片（错）、咖啡→美食（对）、合影→单人照片（错）。**2/6，只证明可运行和保存，不证明适用性或总体准确率。**

另试“先短描述再纯文本分类”与“图像多选字母分类”，结果未改善，因此未把试验提示投入产品。最终保留一次推理独立试验入口，如实披露低准确率，用户可继续选择EmbeddingGemma或E2B。简短描述能工作也不保证无幻觉。完整记录见 [三种试验](smolvlm-initial-probes.json)。这些耗时来自Mac上的模拟器，不可作为Android手机加速承诺。
