# ImagePilot 1.6.4 发布记录

## 范围

移动端设置页重组为分类、相册与搜索、修图、数据、外观、关于六组。分类默认展开；其余保留摘要按需展开。相册权限进入相册组，语言进入外观组。全部业务操作、用户数据及分类规则保持原逻辑。

共用 DisclosureRow：向下展开、向上收起，右箭头仅用于导航。覆盖模型详情、旧模型、分类匹配细节、图片诊断；首页更多筛选同步方向。统一设置行、关闭、目录快捷图标为现有 Ionicons；保留原有用户自定义分类图标。

SettingsGroup 隐藏而不卸载内容，折叠不会重置组内模型选项或终止操作。可访问名称包含摘要，关闭及目录移除按钮提供名称。使用现有明暗主题令牌，无新增运行时依赖。

## 验证

45 套件、312 项自动测试通过；新增折叠方向、读屏状态与子组件保持挂载回归。独立静态审查发现的按钮名称和摘要读屏问题已修正。

独立 iOS 模拟器包显示实际 SettingsScreen（设置读取使用无用户数据的测试值），已查看中文浅色与深色放大字体截图。模拟器 UI 自动点击接口不可用，交互状态由组件测试覆盖；不宣称完成全部真机触控或 Android 实机验证。

## 发行进度

Android 及 iOS 最终构建、签名与下载验证待完成。iOS 目标 1.6.4 build 37；App Store 中英文资料位于 docs/appstore/1.6.4。未上传或提交 App Store。
