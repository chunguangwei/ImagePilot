# ImagePilot 1.5.100 发布记录

## 变更

- Android / iOS 的 Gemma 2 视觉 token 从70调整为140；E2B配置不变。
- 保持模型、JPEG字节输入、768最长边、CPU两线程、提示词和评分规则不变。无需重下模型，旧照片需要主动重新AI分类。
- 分类诊断增加 `visionTokensPerImage: 140`。iOS版本1.5.100 build29。
- 机柜样本的同字节模拟器对照：70拒判，140正确接受电子产品，分差0.046701。不能代替安卓真机验证；持续耗时与发热待用户测试。
