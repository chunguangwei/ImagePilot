# 1.6.5 箭头审查

规则：收起状态显示向下（提示展开），展开状态显示向上（提示收起）；返回/上一项向左，前进/下一项向右。纵向图片导航上一项向上、下一项向下。

已核对源码中的状态、条件内容、点击回调：
- SettingsGroup：六组，隐藏内容与 expanded 同源，折叠不卸载。
- 本地分类入口：classifierExpanded 同时控制模型列表和 DisclosureRow。
- ClassifierModelPicker：每个模型详情分别保存状态；旧模型入口使用 legacyOpen。
- 自定义分类 MatchingFields：expanded 同时控制场景/排除字段。
- 图片信息诊断：showModelDetails 同时控制详情与箭头。
- 首页更多筛选：advancedExpanded 同时控制筛选区域与箭头。
- 移动端返回按钮均调用 goBack 或对应关闭/返回操作；幻灯片左/右分别 index-1/index+1。
- 桌面下拉框 showDropdown 为真显示 ▲ 并显示列表；图片和搜索左右导航索引方向一致；修图结果上下导航索引方向一致。
- 共享 ActionButton/Row 右箭头表示进入详情、系统页面或操作入口，不用于上下展开。修图预设已使用明确编辑按钮。
- 检索文字箭头、图标名、旋转/镜像样式及中英文本，没有发现反向控制或箭头旋转覆盖。

新增交互回归：模型详情与旧模型列表反复展开/收起，核对内容可见性、箭头和 accessibilityState 同步，以及不同区域互不串状态。全套 45 suites / 313 tests 通过。

1.6.4 APK 内 Ionicons.ttf 与依赖字体 SHA-256 一致；直接渲染 chevron-down/chevron-up 字形确认方向正确。静态核查与组件测试未发现反向，不等于完成所有设备的触屏验证；尚无用户所述异常的具体截图。
