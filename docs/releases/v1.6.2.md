# ImagePilot 1.6.2 发布记录

## 变更与验证

内置分类支持编辑规则、补充场景和排除项、恢复默认；规则覆盖单独存入设置，保存和重置不会自动重分类已有照片。备份新增可选规则字段，兼容旧备份并保留本地已有规则。强化人物主体与景观背景的区分，保持 140 token、最高有效分数和 0.50 低分兜底。修复 iOS 扫描读旧记录失败后继续写入及旧库拍摄参数索引创建顺序问题。

44 套件、309 项自动测试通过；旧 SQLite 缺列迁移连续运行两次保留分类、描述和检测字段。独立发布审查未发现阻断回归，15 项重点测试通过。正常更新不会自动修改已分类记录；未测试最早 App Store 安装包的完整真机升级，不能承诺所有历史数据库和异常操作均无风险。

iOS Release 编译和严格签名校验通过。1.6.2 build 32 已覆盖安装并启动于 iPhone 13，没有卸载正式应用。隔离测试应用运行生产分类链路：机柜→电子 0.7402、奖杯→艺术 0.7034、合影→社交 0.6757、湖景→风景 0.7422、游泳→运动 0.7702。诊断均确认 primary-subject-v2、highest-score-v1、140 token。测试应用已删除，正式应用已重新启动。

结果见 [真机实验](../experiments/embedding-iphone13-rules-162-20261107.json)。机柜为原图，湖景/奖杯/合影为截图照片区域；游泳沿用 1.6.1 的 Wikimedia Commons 样本。未新增户外人像评测，五图通过不代表所有类别准确率。Android 无连接真机，原图效果仍需用户复测。
