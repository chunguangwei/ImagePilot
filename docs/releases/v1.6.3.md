# ImagePilot 1.6.3 发布记录

## 修改

移除运动健身的游泳默认描述、参考样本和子类型，保留跑步、球类、骑行、健身。泳帽标签纠正并归服饰。用户追加反馈的宣传图误分“青年”已纳入：补充场景采用原始规则与规则内场景两份参考的平均分，原始文字不改写；商品补充产品详情/功能宣传图。规则版本 rule-scenario-v4，保持 highest-score-v1、140 token 和 0.50 低分兜底。

这是软性的语义匹配，平均分不构成逻辑 AND、独立规则门槛或人数/年龄检测。用户已编辑规则和已有照片分类不自动改动；只影响后续或主动重新分类。

iOS Release 归档、严格签名校验通过，1.6.3 build 34 已覆盖安装并启动于 iPhone 13。隔离真机使用用户截图中的“青年”规则、场景与排除项：机柜→电子0.7402、奖杯→艺术0.7034、合影→社交0.6757、湖景→风景0.7422、急流→风景0.6853、设备宣传图→商品0.6923。合影的青年候选被排除。测试应用已移除，正式应用已启动。
