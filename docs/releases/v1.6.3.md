# ImagePilot 1.6.3 发布记录

## 修改

按用户要求移除运动健身的游泳默认描述、参考样本和子类型，保留跑步、球类、骑行、健身。泳帽标签纠正为泳帽并归服饰。规则版本 primary-subject-v3，保持 highest-score-v1、140 token 和 0.50 低分兜底。用户已编辑的规则与已有照片分类不自动改动。

## 验证

44 套件、309 项 src 自动测试和旧 SQLite 迁移回归通过；独立代码/文案审查未发现阻断项。iOS Release 归档及严格签名校验通过，1.6.3 build 33 已覆盖安装并启动于 iPhone 13。

本地模拟器与 iPhone 生产分类链路均验证机柜→电子、奖杯→艺术、合影→社交、湖景→风景、急流→风景。iPhone 急流分数 0.6853，湖景 0.7422。除机柜原图外，使用截图照片区域；不能把结果等同于 Android 原图验证，也不代表所有类别准确率。见 [真机报告](../experiments/embedding-iphone13-rules-163-20261107.json) 和 [模拟器报告](../experiments/embedding-rules-163-20261107.json)。测试应用已移除，正式应用已启动。
