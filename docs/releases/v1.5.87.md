# ImagePilot 1.5.87 发布记录

## 1.5.87：描述生成修复与配置简化（2026-11-06）

- 修复 Android 旧架构缺少 `clearCache` 原生桥接，导致 LFM 每张图片生成前失败、描述为空的问题；补丁由安装依赖时自动应用。
- EmbeddingGemma 类别编码改用官方 `task: classification | query:` 前缀；保留完整类别含义和自定义规则。相似度仍不是概率，单人照片准确率需更多原图回归。
- 描述开关归入已选中的 EmbeddingGemma，打开后展开“下载并启用”；下载完成自动生效，关闭保留文件。移除语言按钮，中文系统生成中文，其它系统语言生成英文。
- 图片信息显示描述生成状态和失败阶段，失败保留已有描述。Gemma 名称完整换行，移除多余选择圆圈。
- Android 应用内下载或安装失败时提供下载页入口；安装器启动界面也保留手动下载安装入口。
- Android/iOS 均更新至 1.5.87，iOS build 13。iOS 签名与分发状态以发布页实际附件说明为准，不将未签名归档视作可直接安装包或 TestFlight 发布。

Android 正式签名构建已成功，APK 版本、签名及原生桥接均已核验。

iOS 使用 Xcode 27 构建，最低系统版本统一为 iOS 15（Podfile 原已声明 15，修正 post_install 与工程仍为 14 的不一致）。

内置类别采用完整英文类别含义与简短英文视觉标签两种参考，按每类最佳余弦匹配排序；用户规则/描述仍单独编码，不被简短标签绕过。类别缓存包含全部参考文本，图片仍只编码一次。公开单人肖像、猫、咖啡及用户活动合影样本的真实向量对照均命中预期类别；样本量有限，不代表整体准确率。

## 验证结果

- 90 项自动测试通过；两次独立代码审查未发现阻塞问题。
- Android 模拟器：撤掉旧架构 clearCache 桥接后，真实 LFM 两张均失败，错误 `clearCache is not a function`；补齐后两张均生成英文描述，SQLite 读回 message 与 generated 状态成功。英文与系统语言一致。
- iOS 模拟器：官方 EmbeddingGemma + LFM CPU 模型顺序运行，合影归社交活动、公开单人肖像归单人照片；每轮两条中文描述成功保存及读回。中文与系统语言一致。
- Android 模拟器的 LiteRT 图像编码触发 SIGILL，因此 Android 验证隔离 LFM；不把 iOS 分类测试冒充 Android 分类真机验证。
- iOS Release 设备包签名验证通过，版本 1.5.87 / build 13，已覆盖安装到连接的 iPhone 13。开发签名 IPA 仅用于已配置设备测试；未提交 App Store。
- Android 正式签名构建使用源提交 `630690ed856fced70b7487f6ef0a463bd361e949`，最终资产与校验值如下。

公开对照样本来自 [scikit-image v0.22.0 测试图片](https://github.com/scikit-image/scikit-image/tree/v0.22.0/skimage/data)：astronaut.png（单人）、chelsea.png（宠物）、coffee.png（食物）。实际界面已核验：仅选中 EmbeddingGemma 后显示描述开关，开关展开下载/启用状态，Gemma4-E2B 名称完整显示且无多余圆圈。

iOS 开发签名测试 IPA：`ImagePilot-ios-1.5.87-b13-development.ipa`（本机测试产物，不作为公开通用安装包）。SHA-256：`3f012426921c63149ff83980b8c6441f67db0c39e1ebfb15a585719b66b0614c`。
