# ImagePilot 1.6.6 / iOS build 39

修复长按进入多选时移除 RefreshControl 导致 Android 原生 ScrollView 子树重建、滚动位置和手势丢失的问题。刷新控件保持挂载，仅禁用手势中的刷新。iOS 同步保留刷新层。

两端统一在固定导航区域显示选择栏，底部操作栏覆盖显示并为列表保留尾部空间；移除日期组动态高度提示。使用根坐标测量以匹配触摸 page 坐标，避免 Android 状态栏偏移。首次 responder 接管事件即处理移动；缓存内容坐标、稳定 cell refs，按帧渐进边缘滚动，选择仅更新范围差异，缓存通知批量发送，未变化缩略图使用 memo。

回归测试覆盖首次接管漏选、刷新回调稳定性、无效坐标、测量频率、根/窗口坐标差异、滚动命中及取消选择回退。新增测试在修复前出现 4 项失败，修复后通过。全套测试结果及发行状态将在验证后补充。

已有照片归属、分类规则、模型及数据库不改变。Android 无已连接设备；iOS 原生手势回归正在隔离模拟器应用中执行，不访问正式相册数据。
