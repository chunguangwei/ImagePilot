# ImagePilot 1.5.99 发布记录

## 变更

- Gemma 2 保持 70 视觉 token，安卓直接传入预处理后的 JPEG 字节，移除额外的 Bitmap 解码 / PNG 重编码。
- 模型文件、分类规则、评分与不确定归类策略不变；无需重新下载模型。iOS 已使用文件字节输入，本次同步版本至 1.5.99 build 28。
- 用户样本的离线对照见[试验报告](../experiments/embedding-official-usage-ab-20261107.md)。不将模拟器结果当作安卓真机精度保证。
