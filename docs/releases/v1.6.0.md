# ImagePilot 1.6.0 发布记录

## 变更

- 双端Gemma 2保持140视觉token，采用最高有效类别分数。分数接近或旧评分意见不同不再拒判。
- 最高有效余弦相似度低于0.50才按低匹配度归入其他；其他不参与竞争。此门槛是初始策略值，不是概率，也不保证识别所有未知内容。
- 自定义原有规则与排除项保留，排除后继续匹配下一类别；没有有效类别时兜底其他。
- 无需重新下载模型，不增加推理次数；原有照片主动重新分类后生效。评分策略highest-score-v1，iOS build30。

## 验证

- 新判别测试先在旧实现下失败；实现后40套 / 295项测试通过。
- 覆盖最高分、极小分差、稳定同分、0.50门槛边界、其他不参与竞争、自定义排除后继续匹配、无有效类别、无效分数错误、诊断与落库。
- package/lock/Android/iOS版本一致性通过；iOS Release构建及严格签名检查通过。
- 正式iOS1.6.0 build30已覆盖安装iPhone 13并成功启动；隔离测试应用已移除。Android签名产物验证见下文。
