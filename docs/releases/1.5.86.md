# ImagePilot 1.5.86 — 可选离线图片描述

设置 → 分类模型 → EmbeddingGemma 2 下新增 **AI 图片描述（可选）**：

- 默认关闭，独立下载 LFM2.5-VL-450M，约 419 MB；无需下载 E2B。
- 语言可选跟随应用、中文或 English，中英文共用权重。
- EmbeddingGemma 先分类，释放后由 LFM 生成描述，保存到图片信息并可搜索。
- 生成失败保留原描述，不自动使用外部 API；可停止处理。
- 模型下载采用字节数和 SHA-256 校验，支持取消与断点续传。

启用描述会增加耗时和耗电。首次测试建议选少量照片重新执行「AI 分类」；打开开关不会自动补写全部历史图片。中途停止后，尚未生成描述的图片需要手动重新运行。

Android、iOS 代码均接入 CPU 两线程推理；本次发布仅 Android。编译通过不代表所有手机的速度、温升或中文描述质量已验证。
