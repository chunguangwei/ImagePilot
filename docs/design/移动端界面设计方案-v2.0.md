# ImagePilot - 移动端界面设计方案 v2.0

## 📋 文档信息

- **项目名称**: ImagePilot (ImageClassifier App)
- **平台**: React Native (Android + iOS)
- **设计版本**: v2.0
- **创建日期**: 2025-01-20
- **最后更新**: 2025-01-20
- **设计目标**: 基于PC端功能，设计简洁高效的移动端界面

---

## 🎯 设计原则

### 核心原则
1. **功能对齐**: 与PC端保持功能一致
2. **移动优先**: 适配触摸操作和小屏幕
3. **简洁高效**: 减少层级，快速访问核心功能
4. **性能优先**: 懒加载、分页加载优化体验

### 技术约束
- Service层已完成移动端适配（SQLite、ONNX Runtime等）
- 复用PC端的Service层代码
- 使用React Native Navigation

---

## 📱 整体架构

### 导航结构

```
App Root
│
├─ Bottom Tab Navigator (底部导航)
│  ├─ 🏠 HomeScreen (首页)
│  ├─ 📦 StagingBoxScreen (暂存箱) ← 实际是CategoryScreen
│  └─ ⚙️ SettingsScreen (设置)
│
└─ Stack Navigator (堆栈导航)
   ├─ CategoryScreen (分类详情)
   └─ ImagePreviewScreen (图片预览)
```

### 页面清单

| 序号 | 页面名称 | 类型 | 主要功能 | 说明 |
|------|---------|------|---------|------|
| 1 | HomeScreen | Tab | 统计概览、分类入口、最近照片 | 首页 |
| 2 | StagingBoxScreen | Tab | 暂存箱管理 | 复用CategoryScreen |
| 3 | SettingsScreen | Tab | 应用设置 | 设置页 |
| 4 | CategoryScreen | Stack | 通用列表页（分类/城市/相似组） | 核心通用页 |
| 5 | ImagePreviewScreen | Stack | 图片预览和操作 | 详情页 |

**总计**: 5个页面（3个Tab + 2个Stack）

### 2. 按内容分类区

#### 布局
- 横向滚动（ScrollView horizontal）
- **显示规则**: 显示所有存在的分类（有多少显示多少）
- 卡片尺寸：100-120px宽 x 140-160px高
- 卡片间距：8-12px

#### 分类卡片组成
```
┌─────────┐
│  [图]   │ ← 代表图（80x80px，圆角8px）
│  🖼️截图  │ ← 分类名（12-14px）
│   45    │ ← 数量（16-18px，加粗）
└─────────┘
```

#### 数据结构
```javascript
// 从缓存获取分类统计
const cache = GlobalImageCache.getCache();
const categoryCounts = cache.categoryCounts; // { screenshot: 45, document: 23, ... }

// 构建分类列表
const categories = Object.keys(categoryCounts)
  .filter(catId => catId !== 'tobecleaned') // 排除暂存箱
  .map(catId => {
    const categoryConfig = configService.getCategoryConfig(catId);
    return {
      id: catId,
      icon: categoryConfig.icon || '📁',
      name: categoryConfig.name || catId,
      count: categoryCounts[catId],
      thumbnail: null  // 懒加载：滚动到可见时再获取
    };
  });

// 获取某个分类的代表图（懒加载）
const getCategoryThumbnail = async (categoryId) => {
  const images = cache.allImages.filter(img => img.category === categoryId);
  return images.length > 0 ? images[images.length - 1].uri : null;
};
```

#### 交互
```javascript
onPress: (category) => {

    category: category.id,
    fromScreen: 'Home'

}
```

const cities = Object.keys(cityCounts)
  .map(cityName => ({

### 数据加载策略

#### 加载优先级

**第一优先级（立即加载）**:
```javascript
await Promise.all([
  loadStatistics(),      // 统计数字
  loadCategories(),      // 分类列表
  loadRecentImages(12)   // 最近12张
]);
```

**第二优先级（延迟100ms）**:
```javascript
setTimeout(() => {
  Promise.all([
    loadSimilarityGroups(8),  // 相似组（前8个）
    loadCities()              // 城市列表
  ]);
}, 100);
```

**第三优先级（滚动到可见时）**:
```javascript
// 分类代表图（懒加载）
onScrollToCategory: () => {
  loadCategoryThumbnails();
}

// 相似组缩略图（懒加载）
onScrollToSimilarity: () => {
  loadSimilarityThumbnails();
}
```

#### 刷新策略

**下拉刷新**:
```javascript
onRefresh: async () => {
  setRefreshing(true);
  await loadAllData();
  setRefreshing(false);
}
```

**自动刷新（扫描完成后）**:
```javascript
// 监听扫描完成事件
GalleryScannerService.on('scanComplete', () => {
  loadAllData();
});
```
